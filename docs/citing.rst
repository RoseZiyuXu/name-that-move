Citing Name That Move
=====================

Name That Move is the open-source package evolution of prototype movement-
recognition systems used in the publications below. The papers document the
research lineage and earlier applications; they do not describe every API or
implementation detail of the current ``0.1.0`` package.

What to cite
------------

* **When using the software**, cite the specific Name That Move release so
  readers can identify the implementation and version used.
* **For the technical and performance-system background**, cite
  *Human-Machine Ritual: Synergic Performance through Real-Time Motion
  Recognition*.
* **For the dance-performance and attentive-machine-learning context**, cite
  *Creativity ≠ Generativity: A Case Study of Attentive Machine Learning in
  Dance Performance*.
* When a project substantially draws on both the implementation and its
  research context, cite the software and the relevant paper or papers.
